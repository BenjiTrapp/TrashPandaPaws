# The New Raccoon Logo in the C2 — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The operator console carries the new raccoon artwork — animating — as both its header logo and its browser-tab favicon, generated from one committed GIF.

**Architecture:** `static/logo.gif` becomes the brand source. `tools/make_brand_assets.py` stops cropping the wallpaper and instead reads the GIF's 8 frames, squares and premultiplies each, and writes an RGBA still master, its upscale, the four static favicon sizes, and one 512x64 strip holding all 8 frames at 64px. The page serves the GIF itself in the header through a new `/logo.gif` route, and `animateFavicon()` cycles the strip's cells onto the tab icon at the GIF's own 180 ms instead of painting an invented glow.

**Tech Stack:** Python 3.9; Pillow (tools only, declared in `tools/requirements.txt`); hand-written PNG encoding (`zlib`, `struct`) in the tool and a hand-written PNG reader in the test; vanilla JavaScript inside `software/c2/server.py`'s `_OPERATOR_HTML`; `unittest`; node for the animation harness.

**Spec:** [`docs/superpowers/specs/2026-11-17-c2-logo-design.md`](../specs/2026-11-17-c2-logo-design.md)

## Global Constraints

- **The source artwork is at `/Users/derbenji/Downloads/logo.gif`** and is committed verbatim as `static/logo.gif`. 443x394, GIF89a, 8 frames, 180 ms each, `loop 0`. Do not re-encode, resize or optimise it.
- **Transparent pixels in the GIF carry RGB `(224, 106, 108)`.** Every resample must therefore happen on **premultiplied** data — RGB zeroed wherever alpha is 0 — and be unpremultiplied only when the PNG is written. Resampling the raw frame bleeds that pink into every edge.
- **GIF alpha is binary.** Alpha is 0 or 255 in the source; only the generated PNGs carry intermediate alpha.
- **The still frame is frame 4**, the brightest (sum of the red channel over the 8 frames: 23410104, 23958270, 24590403, 25302075, **25872254**, 25253365, 24264627, 23759884). The generator asserts frame 4 is the maximum rather than trusting this list.
- **`favicon-64.png` is written as cell 4 of the strip**, byte for byte, so the two cannot disagree. The 128, 32 and 16 sizes come from the master by the same reduction.
- **This replaces the design doc's "exact 2x2 average" chain.** The old pipeline could halve exactly because its source was already 256 px; the new source is 443 px, so every size is one premultiplied Lanczos reduction. The test's pixel-exactness claim moves to `--check` (which has Pillow) plus the cell-4 identity above; its hand-derived halving test goes.
- **`test_brand_assets.py` keeps reading pixels with its own PNG reader**, not Pillow — that is why the file has one. Running the generator as a subprocess is a different matter: Pillow is a declared test dependency (`software/tests/requirements.txt` includes `tools/requirements.txt`, and it is installed in `software/.venv` at 11.3.0), and `test_make_gif.py` already runs a tools script this way. So the `--check` test needs no skip gate.
- **No new runtime dependency.** `software/requirements.txt` and `software/c2`'s install line are untouched. Nothing in `software/c2/` imports Pillow.
- **The 683 kB GIF is committed once.** It lives in `static/` and reaches the page through a route, never copied into `software/c2/static/`.
- **`static/trashpanda_logo.png` and the `/logo.png` route stay.** Only the header must stop using them.
- `raccoon_face_256.png` and `raccoon_face_512.png` are deleted and replaced by `logo_256.png` and `logo_512.png`. Nothing outside `tools/make_brand_assets.py` and `software/tests/test_brand_assets.py` references the old names (checked).
- Tests are `unittest`, run from the repository root:
  `software/.venv/bin/python -m unittest software.tests.test_brand_assets -v` — 20 tests, green at this plan's base.
  Full suite: `software/.venv/bin/python -m unittest discover -s software/tests -t .`
- The generator runs on an interpreter that has Pillow: `python3 tools/make_brand_assets.py` (system `python3`, Pillow 11.3.0, verified).

## Review Focus

Five conditions the spec implies that no happy path covers. Each one's test is named in brackets.

- **The strip fails to load** — wrong path, a half-written file, the route gone — must leave the static PNG favicon in the tab, not a blank icon, and must not retry forever. [Task 4]
- **A tainted or disabled canvas**: `toDataURL` throws, and it would throw every frame. One `return`, not ten exceptions a second. [Task 4]
- **The tab hidden all day**: the loop must back off rather than redraw an icon nobody can see. The console stays open for a whole shift. [Task 4]
- **An asset edited by hand**: `--check` must say `DIFFERS` for a file that no longer matches what the GIF produces, and must not exit 0. [Task 1]
- **A re-exported artwork with a different frame count**: the page's `FAVICON_FRAMES` and the committed strip's width must not be able to disagree silently — one of them changing without the other is a test failure, not a frozen icon. [Task 2]

```python
class TestTheCommittedAssetsAreWhatTheGeneratorMakes(unittest.TestCase):
    TOOL = REPO / "tools" / "make_brand_assets.py"

    def _check(self):
        return subprocess.run([sys.executable, str(self.TOOL), "--check"],
                              capture_output=True, text=True, timeout=300)

    def test_check_reports_every_asset_as_matching(self):
        done = self._check()
        self.assertEqual(done.returncode, 0, done.stdout + done.stderr)
        self.assertNotIn("DIFFERS", done.stdout)
        self.assertNotIn("missing", done.stdout)

    def test_check_notices_an_asset_edited_by_hand(self):
        target = WEB / "favicon-16.png"
        original = target.read_bytes()
        try:
            target.write_bytes(_Png(target).with_pixel_cleared().to_bytes())
            done = self._check()
            self.assertNotEqual(done.returncode, 0,
                                "--check passed on an edited asset")
            self.assertIn("DIFFERS", done.stdout)
        finally:
            target.write_bytes(original)
```
